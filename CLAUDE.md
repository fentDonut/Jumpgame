# Leg Day (working title) — Project Context

Roblox game: a vertical climbing game where players train and upgrade their legs to jump farther, using a timing-based jump bar, to ascend a sky of islands and clouds that get sparser — and periodically rearrange — the higher you go.

This project replaces the earlier "Infinite Supermarket" concept that used to live in this repo; that design has been retired and its docs removed to avoid confusion.

## Canonical docs

* [**Leg Day - Design Doc.md**](Leg%20Day%20-%20Design%20Doc.md) — current design: core loop, jump bar mechanic, leg progression, world structure, settled decisions, and open questions.
* [**Leg Day - Numbers.md**](Leg%20Day%20-%20Numbers.md) — first tuning pass: jump stat curve, pit gravity table, Leg Level bands, Medal/Coin economies, world geometry and sizes. The design doc owns *what*; this owns *how much*.
* [**Leg Day - Cloud Field.md**](Leg%20Day%20-%20Cloud%20Field.md) — how the sky between islands is generated: settled layout decisions (and the ones already rejected), the connectivity-as-acceptance-filter method, cloud geometry and collision, every parameter, the pitfalls, and the validation a build must pass. Read before touching the clouds — it's the spec to rebuild from, there is no generator checked in.

## The build lives in Studio, not here

The world geometry exists only in the Roblox Studio place, generated by running Luau through the Studio MCP. There are no scripts in the place and Rojo is not set up, so build changes leave no git diff and are lost unless the place is saved in Studio. Back up affected folders to `ServerStorage._IslandBackup` before regenerating anything — `execute_luau` edits are not reliably undoable.

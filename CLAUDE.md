# Leg Day (working title) — Project Context

Roblox game: a vertical climbing game where players train and upgrade their legs to jump farther, using a timing-based jump bar, to ascend a sky of islands and clouds that get sparser — and periodically rearrange — the higher you go.

This project replaces the earlier "Infinite Supermarket" concept that used to live in this repo; that design has been retired and its docs removed to avoid confusion.

## Canonical docs

* [**Leg Day - Design Doc.md**](Leg%20Day%20-%20Design%20Doc.md) — current design: core loop, jump bar mechanic, leg progression, world structure, settled decisions, and open questions.
* [**Leg Day - Numbers.md**](Leg%20Day%20-%20Numbers.md) — first tuning pass: jump stat curve, pit gravity table, Leg Level bands, Medal/Coin economies, world geometry and sizes. The design doc owns *what*; this owns *how much*.
* [**Leg Day - Island Themes.md**](Leg%20Day%20-%20Island%20Themes.md) — the art brief for islands 4–10 and the Summit: theme, palette, hero prop and pit read per island, the cross-cutting light/silhouette/underside rules, and the calls still open. Read before building any island above 3.
* [**Leg Day - Cloud Field.md**](Leg%20Day%20-%20Cloud%20Field.md) — how the sky between islands is generated: settled layout decisions (and the ones already rejected), the connectivity-as-acceptance-filter method, cloud geometry and collision, every parameter, the pitfalls, and the validation a build must pass. Read before touching the clouds — it's the spec to rebuild from, there is no generator checked in.

## The build lives in Studio, not here

The world geometry exists only in the Roblox Studio place, generated by running Luau through the Studio MCP. There are no scripts in the place and Rojo is not set up, so build changes leave no git diff and are lost unless the place is saved in Studio. Back up affected folders to `ServerStorage._IslandBackup` before regenerating anything — `execute_luau` edits are not reliably undoable.

## Check for clipping before calling a build done

**Screenshot whatever you built and look at it.** Every visual fault in this project so far was invisible in the code and obvious on screen. Then check these four, in code rather than by eye:

* **Z-fighting** — surfaces within ~0.03 studs of each other that also overlap in plan flicker into a mottled mess. Separate stacked layers by ≥0.06 studs, alternate two heights around ring groups so neighbours are never level, and delete overlapping scatter rather than stacking it. **The overlap test must know a cylinder from a block**: a rotated cylinder's `Size` describes its bounding box, so a box-based test both misses real clashes and invents fake ones — use the circular cross-section for `Shape == Cylinder`, and compute the true top face from the CFrame rather than `Position.Y + Size.Y/2`. Switching to that test found 118 genuine clashing pairs across islands 2–4 that the box version had reported as clean.
* **Parts through parts** — sign posts placed inside a board's half-width cut straight through the text. Run an oriented-bounding-box overlap test across each prop group; don't trust a glance.
* **Floating parts** — islands sit at real altitudes, so a position vector already carries Y. Adding an absolute height to it parks geometry hundreds of studs away. After every island, scan for parts outside `[surface−145, surface+40]`.
* **Step heights** — anything a player walks over (pit rims, kerbs) must top out ≤1.7 studs above the surrounding surface; the humanoid step limit is 2.
* **See-through shells** — a keel, or any ring of angled facets, is hollow: adjacent plates leave slits and sky shows through them from below. Fill it with a stack of discs on the axis. Size each from the **minimum** radius around that height, not the max — a max follows the spurs and balloons the cone into a bucket. Inset ~2.5 studs so the fill never surfaces through a plate, give consecutive discs radii differing by ≥0.4 so their curved sides don't z-fight, and stop above the solid tip where there are no slits to hide. Keep the fill `CanCollide`/`CanQuery`/`CanTouch = false`: anything queryable under an island feeds the cloud field's raycasts and moves the gate. Verify with radial raycasts (temporarily re-enabling `CanQuery`) — a disc on the axis blocks every radial sightline at its height, so 0% escape is the expected result.

Two Studio quirks that will otherwise cost time: `TextScaled` forces `TextWrapped` on, so a long label breaks where Roblox chooses — split it into separate labels to control the break; and the viewport lags a frame behind SurfaceGui edits, so a blank sign in a screenshot often just needs a re-capture.
